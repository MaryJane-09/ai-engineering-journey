## Takeaway

A `.venv` keeps a project's package installs separate. The learner observed NumPy 2.5.4 in the repository environment and 1.26.4 in `.venv-a`, with interpreter paths inside each environment. The active interpreter path identifies which environment a command uses; the Python version alone does not.
