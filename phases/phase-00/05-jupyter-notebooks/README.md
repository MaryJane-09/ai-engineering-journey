# SE 00 Lesson 05: Jupyter Notebooks

This folder holds the learner's Jupyter lesson artifacts:

- [Experiment](experiment.md): procedure, result, and evidence.
- [Notes](notes.md): lesson concepts and references.
- [Reflection](reflection.md): what the learner understood and questions to revisit.
- [Notebook](notebook-basics.ipynb): the runnable code cells.

Jupyter creates `.ipynb_checkpoints/` as an automatic backup directory. Those checkpoint files are not extra lesson notebooks and are ignored by Git.
