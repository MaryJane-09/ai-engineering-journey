# AI Engineering Journey

This repository records one learner's progress through the [AI Engineering from Scratch curriculum](https://github.com/rohitg00/ai-engineering-from-scratch). It is a personal learning record, not a copy or implementation of the official course.

## How to use this repository

- [`LEARNING.md`](LEARNING.md) is the source of truth for the mission, placement, official roadmap, lesson status, progress log, and review queue. It is maintained by the installed learning skills; keep its lesson order and progress evidence factual.
- [`phases/`](phases/) holds personal notes and evidence arranged by official phase and lesson. Retrospective notes are labeled as summaries; original outputs should remain identifiable as learner evidence.
- `labs/` is for standalone experiments, `notes/` for cross-lesson notes, `projects/` for larger builds, and `reflections/` for broader learning reflections. Create these directories when they have meaningful content.
- [`.agents/`](.agents/) contains installed course skills. [`skills-lock.json`](skills-lock.json) records their upstream sources and integrity hashes; avoid editing skill-managed files as part of ordinary note organization.

The official curriculum repository is the source for lesson content, exercises, and the canonical order. Consult it directly as each lesson is reached; do not copy its phase tree into this personal repository. The current next lesson is SE 00 Lesson 09, Data Management, as recorded in `LEARNING.md`.
